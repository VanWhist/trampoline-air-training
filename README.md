# トランポリン エアトレーニング

全日本スキー連盟「フリースタイルスキー トランポリン エアトレーニング統一指導教程」を、
選手がスマートフォンで技ごとに引けるようにしたアプリです。

収録済み：**02_トランポリン基礎**（47技）／**04_トランポリン中級**（10技）／**05_トランポリン応用**（13技）

公開URL：https://vanwhist.github.io/trampoline-air-training/

ナショナルチームのフィジカル版（`nt-training-menu`）と同じUI・操作性で、
技名をタップすると実演動画がその技の開始秒から再生されます。

---

## 画面の作り

### ホーム
章の一覧と検索。検索は技名だけでなく、**雪上の動きからの逆引き**にも対応しています。

| 検索語 | 出てくる技 |
| --- | --- |
| バックフリップ | 腰落ち |
| コンタクトツイスト | 1/2捻り跳び／フロントハーフ |
| ティルト | 腰落ち→1/2捻って立つ／背落ち→1/2捻って立つ |

### 章の画面
上に実演動画、その下に技を系統別に並べています。教程の掲載順は系統の中で保っており、
各技には教程の通し番号を表示しています。

**トランポリン基礎（47技）**

| 系統 | 技数 |
| --- | --- |
| 基本ジャンプ | 7 |
| 腰落ち・膝落ち | 6 |
| 四つん這い落ち | 6 |
| 腹落ち | 5 |
| 背落ち | 13 |
| 名前のついた技 | 10 |

**トランポリン中級（10技）**

| 系統 | 技数 |
| --- | --- |
| 後方宙返り | 3 |
| 前方宙返り | 1 |
| バラニー | 2 |
| 捻り技 | 2 |
| コディー | 2 |

**トランポリン応用（13技）**

| 系統 | 技数 |
| --- | --- |
| バラニーアウト | 2 |
| ダブルタック | 2 |
| フロントフルインバラニー | 3 |

各系統は「本体＋段階練習」の組。段階練習は `detail` に「◯◯の段階練習」と入れてある。

### 技のカード
表示の順番はこうしています。

1. **雪上へのつながり** … 常時表示。教程の「競技特性」欄の内容
2. **安全上の注意** … 常時表示。畳まない
3. **やり方** … 折りたたみ
4. **注意点** … 折りたたみ

教程の文章は要約せず原文のまま入れ、**見せる順番だけ**を変えています。
教程の「注意点」のうち、ケガに直結する記述（10件）は安全欄に分けて常時表示にしています。

## データの直し方

`data/training-data.json` を編集してコミットするだけです。ビルドはありません。

```
sessions[0].exercises[n]
  no          教程の通し番号（1〜47）
  group       系統
  name        技名
  detail      技名の補足（例：背落ち→1回捻り背落ち）
  aliases     検索用の別名
  start       動画の開始秒（未設定なら null）
  howto       やり方（折りたたみ）
  caution     注意点（折りたたみ）
  safety      安全上の注意（常時表示）
  link        雪上へのつながり（常時表示）
```

`start` は `0` も有効な値です。「未設定」は必ず `null` にしてください。

## 動画の差し込み手順

**トランポリン基礎**は 2026年9月1日に設定済み。動画は japanmogulteam に**限定公開**。

- 動画ID：`9Au31dWnJtA`（27分53秒）
- 47技すべての `start` を設定済み

**トランポリン中級**も 2026年9月1日に設定済み。動画は japanmogulteam に**限定公開**。

- 動画ID：`fvqrVVs-Qkw`（6分51秒）
- 10技すべての `start` を設定済み

**トランポリン応用**は動画が「ツイストの練習」しか収録していない（1分26秒・全編1区間）。
13技のうち `start` が入るのはツイストの練習だけで、残り12技は解説のみになる。

15分を超える動画を上げるには、アカウントの電話番号確認が必要です（未確認だと
「動画が長すぎます」で弾かれます）。この章は27分53秒なので該当しました。
06_種目共通基礎編（33分37秒）も同じです。

動画には BGM（Inspiration / soundaround）への著作権の申し立てが付いていますが、
再生・チャンネルへの影響はありません（収益化した場合のみ影響）。

新しい章を足すときは、`youtubeId` が空のあいだ「動画は準備中です」と表示され、
技の解説は問題なく読めます。開始秒は `admin/timestamp.html` で拾えます。

## 技術メモ

- 依存ライブラリなし・ビルド不要。すべて相対パスなのでサブディレクトリ配信でも動きます
- ルーティングはハッシュ（`#/session/<id>`）。GitHub Pages で404にならないため
- Service Worker：画面まわりは Stale-While-Revalidate、データは Network First
- 教程PDFの原本一式は Dropbox にあります（`Dropbox/Public/強化委員会/2020−2021/助成金/totoくじ/
  タレント発掘事業/FSトランポリンエアトレーニング 統一指導教程/`）。ドライブ共有版に無い
  05_トランポリン応用・09_種目特化エアリアル基礎編はこちらにしかありません。逆に
  02_トランポリン基礎はこちらに無く、ドライブ版のみです
- 教程PDFには文字コード対応表（ToUnicode）が入っておらず、そのままでは本文が化けます。
  並び順がJIS漢字コード順で `文字コード = 0x464 + JISの通し番号` という規則だったため、
  変換表を生成して復元しました。本文はその復元結果です
